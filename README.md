# Semi-synthetic STATS19 Data Capsule Classification Dataset

This release contains an offline vehicle-accident data classification and authentication-decision dataset constructed from UK STATS19 2024 road-safety open data.

This is **not** a complete data-capsule system release. It does not include real data capsules, encrypted payloads, proof bundles, TEE logs, blockchain state, verification keys, zkey/wasm/r1cs artifacts, private keys, tokens, backend services, frontend applications, or runtime system logs.

## Dataset Size

| Split / file | Rows |
|---|---:|
| Full dataset (`processed_data/accident_capsule_dataset_full.csv`) | 5,500 |
| Tune split (`processed_data/accident_capsule_tune.csv`) | 3,850 |
| Test split (`processed_data/accident_capsule_test.csv`) | 1,650 |
| Final classified test (`processed_data/accident_capsule_classified_test_final.csv`) | 1,650 |

## Included Files

- `processed_data/accident_capsule_dataset_full.csv`: full semi-synthetic offline experiment table.
- `processed_data/accident_capsule_tune.csv`: fixed tune split used for parameter selection in the offline experiment.
- `processed_data/accident_capsule_test.csv`: fixed test split used for final evaluation and replay checks.
- `processed_data/accident_capsule_classified_test_final.csv`: final test table with base/PTFa/auth/proof-mode decision outputs.

## Field Groups

The CSV files include:

- STATS19-derived accident fields such as collision severity, vehicle/casualty counts, road type, weather, and time fields;
- semi-synthetic `content_*` fields for offline data-content sensitivity experiments;
- semi-synthetic `access_*` fields for task/request-context experiments;
- `output_scope`, representing the requested/used output-scope category in the offline policy experiment;
- final-file decision outputs including base, PTFa, authentication, and proof-mode fields.

Important label caveat: `base_manual_label`, `access_ptf_reference_level`, and `required_auth_manual_label` are rule-reference or policy-reference labels. They are **not independent human annotations** and should not be described as external ground truth.

Important identity caveat: `content_driver_did`, `content_vehicle_did`, and `content_plate_hash` are semi-synthetic experiment fields. They are not real identity credentials, real license plates, or cryptographic keys.

## Raw Data

Raw STATS19 CSV files are not included in this release package. Users who need the original source data should obtain the official UK Department for Transport STATS19 2024 road-safety open data from the official source and cite it according to the official terms.

## Intended Use

This dataset is intended for reproducing the offline data-classification, authentication-decision, and policy-ablation experiments described in the associated paper/project materials.

## Not Intended For

- Running a production data-capsule system;
- cryptographic proof generation;
- TEE or blockchain deployment;
- evaluating independent supervised-learning generalization from leakage-free human labels;
- identifying people, vehicles, or real-world credentials.

ML baseline results on this dataset should not be interpreted as independent generalization performance because several labels and fields are generated by related rules in the semi-synthetic pipeline.
