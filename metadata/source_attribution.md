# Source Attribution

The original road-safety source data are UK Department for Transport STATS19 2024 road safety open data.

This release package does **not** mirror or redistribute the raw STATS19 CSV files. Users who need raw source data should obtain it from the official UK Department for Transport source and cite it according to the official source and license.

The included CSV files are processed, semi-synthetic offline experiment tables derived from STATS19 records. The project adds semi-synthetic `content_*`, `access_*`, `output_scope`, and authentication-decision fields for data-classification and policy-analysis experiments.

This package is not a data-capsule runtime artifact and does not include encrypted payloads, proof bundles, TEE logs, blockchain state, keys, tokens, or backend/frontend system files.
